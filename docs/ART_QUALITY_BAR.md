# 美術品質標準

使用者於 2026-11-08 明確指定：以 3A 大作的視覺質感為目標，不接受粗糙積木人偶作為正式角色交付。

## 驗收原則

- 面數、檔案格式、骨架與材質槽只是技術門檻，不能據此宣稱達到成品品質。
- 人物需有可信的人體比例、臉部結構、手部、自然衣褶、衣料厚度、合理的接縫與層次；避免球體頭、圓柱肢體與互相穿插的積木外觀。
- 材質需分辨皮膚、濕毛料、皮革、木材、氧化金屬；磨損與污漬要對應使用位置，不能只鋪均勻雜訊。
- 三視圖、近景、全身轉台與實際遊戲鏡頭中均須檢查剪影與細節。概念圖不能替代模型驗收。
- 肩、肘、膝、髖在走跑、翻滾、攻擊與倒地時不能明顯斷裂、塌陷或穿模。翻滾、扛人、敲鐘及敵人專屬攻擊不能只換檔名重用同一動作。
- 必須在 Godot 夜景、霧、暖光下檢查；不能只靠棚拍渲染或景深掩蓋問題。
- 每次交付註明：概念草案、模型研究、待驗收候選或已驗收。未過關的實驗稿不放進 art-inbox 當正式交件，不替換運行時素材。

## 預算與流程

原 ART_REQUESTS 的面數與貼圖預算繼續有效。3A 質感目標不等於無限制增加面數或貼圖尺寸；調整預算前應以實際鏡頭與效能測量作依據。

先做一位角色的完整品質樣本：造型與多視圖 → 高品質基礎網格／雕塑 → 拓撲與 UV → PBR 材質 → 蒙皮 → 一組代表動作 → Godot 實景驗收。樣本達標後再擴展到其他角色。

AI 3D 生成只是起點；生成結果仍須修形、處理遮擋／背面、拓撲、材質與綁定。Blender 已安裝，可用於後處理。fal 已找到但尚未確認連接，不可記作已能使用。
