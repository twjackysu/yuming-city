# 試玩指南：《霜橋鎮的第九聲鐘》

給 Jacky（和之後的試玩者）。整段約 20～30 分鐘；跑兩次（兩條路線）約 45 分鐘。感想直接寫在 [`FOR_JACKY.md`](FOR_JACKY.md) 最下面「回覆」區，或開 GitHub Issue，一句話也有用。

## 準備（2 分鐘）

1. 到 [Releases → latest](https://github.com/twjackysu/yuming-city/releases/tag/latest) 下載 `YumingCity-windows-x64-*.zip`，解壓，雙擊 `YumingCity.exe`。
2. 鍵鼠或手把都可以（XInput 手把：Xbox、或 Steam 模擬的手把）。第一次建議用你平常玩 ARPG 的那一種，第二次換另一種。
3. 開場 Esc（手把 Start）→ 設定：難度預設「標準」，想專心看劇情可以選「故事」。

## 路線（每段大約幾分鐘）

不知道去哪就跟著畫面上的**小菱形＋距離**走（設定裡可以關）。

| # | 段落 | 你要做的事 | 約 |
|---|---|---|---|
| 1 | 廣場 | 先往南走進南街看一眼倒塌的石拱（諾恩會想起爸爸，日記多一條）。再到右前方梨販攤說話 | 3 分 |
| 2 | 鐘樓 | 沿主街往北走，爬上石階到鐘樓；**每按一次 F／A 敲一下，親手敲九下**（按住 F／A 可以跳過演出） | 3 分 |
| 3 | 北街 | 第九聲北街陷落。找提燈旁的受困者，**按住 F／A 搬開瓦礫**；救出三人席菈出現 | 4 分 |
| 4 | 席菈 | 走到她身邊對話（「你敲了幾下」可以說謊）→ 和她一起打倒灰巡者（按住右鍵／LT 看穿，Q／十字鍵上 叫她打弱點） | 5 分 |
| 5 | 南街 | 回廣場往南走，送葬者戰開打：護送傷者車隊穿過石拱到路口。送葬者舉起鐵架時，二選一（見下） | 6～10 分 |
| 6 | 收束 | 回梨販攤和艾妲說話（她說今晚死了幾個人，跟你救了幾個、車隊被打幾下有關）→ 走進攤子東邊的地窖蓋板 | 3 分 |
| 7 | 第 1 章（白盒，新） | 走進地窖後出現章節卡「第一章　攻略之外的門」→ 酒館：走到傷者旁邊的席菈 → 入夜走到晚餐桌（席菈灑湯時選替她拿或不動）→ 走到東南角的小桌子畫地圖，**逐條點選哪些攻略「我不確定」**，按「就這樣」→ 走出門口是**隔天早上的霜橋鎮**（陰天、路燈熄了）：走上昨晚的北街（席菈的對話）→ 到梨販攤旁的地窖門口找艾妲拿油燈（諾恩左手的提燈換成圓肚銅油燈）→ 走進地窖是**一百七十二階**（螺旋往下、很暗）：走到一半諾恩會攔住大家，這時可以按互動鍵**往前丟一塊石頭**，也可以不理他直接走過去（兩種都試試看，結果不一樣）→ 走到底的門口，柯德開門出來（回答他的問題有三種）→ **走進白晝城（新）**：一整片白、沒有影子的地底城，只有你手上的油燈會投影子（席菈走在旁邊時看看牆上）→ 先走到右邊那座黑色的鐵爐旁邊 → 跟著柯德走到路口的黑色石碑（有個女人在換水，看她名字後面的數字），可以走到石碑前按互動鍵把手按上去 → 走到街尾左手邊柯德家的門口：**畫面黑一下進到屋裡吃晚餐（新）**，小女兒問你問題時可以回答或不回答，席菈放乾糧之後你可以跟著放或不動 → 吃完回到街上往街尾的鐘院走：**路上的小女孩與席菈的兔子（新）**，之後街中間那根石柱可以真的撞上去（也可以繞開）→ 鐘院門口第 1 章結束 → **第 2 章「城主的飯桌」（新）**：走到桌邊，城主伊薩替你拉椅子；吃飯的對話之後**對伊薩按住 V（看穿）**，看攻略裡的稱號一個字一個字被劃掉（不按也可以，等一下他會自己開口）→「他自願的。」可以先開口道歉或不說話 → **走到北牆的門前進鐘院內室（新）**：黎歐的過場（可以按住 F 跳過）→ 走到左邊牆上的 4 塊浮雕前按互動鍵，一塊一塊看（順序隨意）→ 看完之後伊薩走到右邊牆上的窗前，**走到他旁邊（新）**：席菈說「把人撤走」，你可以問「毀掉鐘」「地上的援軍」或直接沉默 → 他拉開窗簾（過場，可以跳過）→ 第 3 章章節卡 → **乾運河（新）**：沿東岸往北走到吊樑旁的岸邊 → 對話（「我去引開牠。」）→ 再往前走進岸邊的水溝（三個人趴下）→ 選節奏讓席菈敲，看送葬者怎麼反應（不動／偏頭／轉頭；轉頭前鏈子會先響，設定頁「觀察提示音」可關）→ 找到速度之後 → 出現「待續」。樓梯夠不夠暗、看不看得到路、鏡頭在轉角會不會卡牆；**白晝城第一眼有沒有「這裡不對勁」、會不會白到刺眼**、柯德家屋裡油燈在牆上投的大影子（太嚇人還是剛好）、撞柱子好不好笑、**看穿伊薩時劃字的速度與那一刻有沒有感覺**、**內室的暖光第一眼（跟外面的白對比夠不夠）、細管裡的光流得太快或太慢**、一巴掌那一聲、**窗外那隻眼睛的第一眼（夠不夠嚇人、網格會不會像鐵絲網、睜眼和瞳孔收窄的速度）**、**乾運河的第一眼（光條夠不夠明顯、掛著的送葬者會不會太早嚇到、鐘舌一閃一閃像不像心跳）**，都想聽。房間與人物都還是方塊與程序人偶，請只看流程與對話；白天的霜橋鎮第一眼（太亮、太灰、像傍晚？）也想聽 | 8 分 |

### 兩條路線（第 5 段）

- **重現路線**：走到石拱旁按住 V／Y 一秒「重現」石拱，擋下鐵架。按住時畫面右側會出現你要付出的記憶——**永遠忘掉和父親在石拱下的最後一次對話**。之後打開日記（Tab／View），那段變成被剪掉的空白；收束時對艾妲說不出某句話。
- **燃燒劍路線**：不重現。席菈會提前燒自己的劍，在車隊前把鐵架斬成兩截；記憶還在，但她的手傷了（收束時艾妲會注意到）。

第二次玩：Esc → 回標題 → 新遊戲，選另一條。

## 最想聽的感想（挑你有感覺的回就好）

1. **第一眼**：進霜橋鎮那一刻的氣氛（霧、暖光、半木構房子、往鐘樓爬坡的石階）。哪裡最「假」？
2. **敲鐘九下**：親手敲有沒有份量？第九聲北街陷落有沒有嚇到？
3. **打擊感**：鐘錘打中、灰巡者跪地、閃避的手感。太慢／太快／太軟？
4. **重現的代價**：按住時看到要付出的記憶，會不會猶豫？日記被剪掉那一下有沒有感覺？
5. **送葬者的鐵架**：知不知道該去石拱？鐵架撞碎／被斬成兩截好不好懂？
6. **席菈**：像一個有自己想法的人嗎？（拒絕閃開、手傷、「你敲了幾下」）
7. **鏡頭**：過肩鏡頭（諾恩在畫面左邊）跑起來舒服嗎？貼牆、窄巷、打鬥時有沒有鏡頭突然跳動或穿牆？
8. **指引與提示**：小菱形會不會太「遊戲」？有沒有卡住不知道做什麼的地方（在哪一段、多久）？
9. **用詞**：還有看不懂或太武俠的字嗎？

壞掉的東西（卡住、穿牆、畫面怪、字沒翻譯）：截圖或一句描述＋在哪一段即可。

## 效能量測（另外 1 分鐘）

在解壓資料夾開 PowerShell：

```
.\YumingCity.exe ++ --benchmark
```

約 35 秒後自動結束，結果在 `%APPDATA%\YumingCity\benchmark\bench-*.json`。把 JSON 內容貼到回覆區，並寫上**顯示卡型號與螢幕解析度**。目標：中階獨顯 1080p 中等畫質 60 fps（每幀約 16.7 ms）。

## 直接練某一段

```
.\YumingCity.exe ++ --level=frostbridge --convoy            # 南街送葬者戰（加 --phase2 從第二階段開始）
.\YumingCity.exe ++ --level=frostbridge --rescue            # 北街救援
.\YumingCity.exe ++ --level=sandbox --enemies               # 沙盒裡的灰巡者
.\YumingCity.exe ++ --level=canal                           # 第 3 章開頭：乾運河
.\YumingCity.exe ++ --level=canal --canal-at=drain          # 第 3 章段落 2：趴在水溝裡選節奏
```
