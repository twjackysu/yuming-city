# 試玩指南：《這些詛咒對我太有用了》前十分鐘＋地下市場

約 20 分鐘。感想寫在 [`FOR_JACKY.md`](FOR_JACKY.md)「回覆」區，一句話也有用（**哪一段畫面最差**最有用）。

## 準備（2 分鐘）

1. 到 [Releases → latest](https://github.com/twjackysu/yuming-city/releases/tag/latest) 下載 `YumingCity-windows-x64-*.zip`，解壓，雙擊 `YumingCity.exe`。
2. 標題畫面按「**新遊戲**」。鍵鼠或手把都可以（XInput 手把：Xbox、或 Steam 模擬的手把）。
3. 想專心看內容：Esc（手把 Start）→ 設定 → 難度選「故事」。

不知道去哪就跟著畫面上的**小菱形＋距離**走（設定裡可以關）。

| 3 | 南街口 | 霧散了，繼續推車到南街口，席菈從麵包店出來，走到她旁邊 | 1 分 |
| 4 | 守衛戰 | 和席菈打倒南街的送葬者。牠胸口的管子發綠光＝要噴毒（地上虛線圈是落點）：**毒會讓你回血，爪子和下砸照樣會痛** | 3～4 分 |
| 5 | 藥箱 | 牠倒下後背上的箱子摔在旁邊，走近按 F／A 拿兩瓶。按 1／十字鍵左喝一口（滿血會先問；不想喝就走開） | 1 分 |

| 7 | 地下市場 | 貨梯停在高台上，往下是一條攤販街。走下木坡道（席菈會說這裡的規矩）→ 沿街走到街底**綠色窗戶**的藥店門口（門開著）。這一段沒有戰鬥，請看**畫面**：第一眼、布棚、燈籠、街底的綠光 | 1 分 |
| 8 | 彌夏的藥店 | 從開著的門走進去，走到櫃台前彌夏會開口（她以為你來鬧事；生命是滿的話她會先扎一針，扣 3 點）→ 站到櫃台上的**測試板**前（有刻度盤的那塊），畫面下方出現「按住 F／A　把手放到測試板上」→ **按住 2 秒**（放開會歸零）→ 指針甩到綠色那邊、板上的綠燈亮、生命條慢慢往上 → 約 3 秒後彌夏願意談，最後把人指到黑市示範場（席菈會先到門外等）。請看：店裡會不會太暗、按住的提示看不看得懂、席菈會不會擋住鏡頭或卡在門口 | 2 分 |
| 9 | 黑市示範場 | 走出藥店往北走，街中段左手邊（西側）有一座**示範台**：兩幅紅白直條紋的布、一串燈籠、聚光燈下一個舉著護腕的紅衣商人，台下有人在看。走到台前幾步商人開始叫賣（八句對話）。**講完再往台子走近一點就開打**：席菈頭上一句「再示範一次。這次不准喝解藥。」，看熱鬧的人往北跑開，兩個胸前掛紅白布條的守衛過來——**拿棍子的**（棍頭的銅箍亮起來＝要打了；橫掃很寬、直刺很遠）和**戴護腕的**（出拳非常快，但每打完一拳右手會垂著僵住快 2 秒、護腕閃暗紅——這時候打他）。這一場沒有毒，中毒回血幫不上忙；席菈會自己打，你不動她也打得完。兩個都倒下 → 商人把護腕丟過來（五句對話），右上的目標變成「回彌夏的店：先在測試板上試護腕」。倒下重來會回到台子南邊幾步，守衛滿血。請看：**打起來順不順、會不會太簡單或太久**；戴護腕的「打完會僵住」看不看得出來；席菈會不會卡住；看熱鬧的人跑開的時候會不會擋到你 | 2 分 |
| 10 | 試戴護腕 | 往南走回街底的藥店、走到櫃台前 → 彌夏四句對話（她的規矩：先戴上、手放到板子上，板子說危險就拿下來）→ 站在測試板前**按住互動鍵 2 秒**（提示「把戴著護腕的手放到測試板上」；指針先往紅的那邊擺，放開會歸零）→ 按滿：畫面中央兩行字「【麻痺】／【第二格反轉】麻痺 → 出手加速」，指針翻到綠的那邊、綠燈亮，左下生命條上面多一行**黃色閃電**「麻痺 → 出手加速 12」，諾恩右手前臂上多了護腕（兩圈冷光）。**這 12 秒按攻擊鍵揮幾下：出手比平常快**（只有出手變快，走路、閃避不變）→ 3 秒後彌夏講結果（四句）。請看：那兩行字與左下的新狀態**看不看得懂「麻痺在他身上變成加速」**；揮起來**感覺得到變快嗎**（現在是 1.35 倍）；護腕在手上看不看得到 | 2 分 |
| 11 | 兩格一起用（小戰） | 聽完彌夏講結果，右上的目標變成「走出藥店」→ 走出門：街上站著三個人（兩個胸前有紅白布條、拿棍子的，後面一個**腰上掛一排綠瓶子**的），商人在最後面指著你 → 四句對話 → 開打，畫面上方一行提示。**丟毒瓶的**會把發綠光的瓶子舉過頭再丟過來，落地一團綠霧（3 秒）：**站進去生命會往上**（左下「中毒 → 回血」）；**每打中人一下**左下就有「麻痺 → 出手加速 6」，一直打得到人就一直快，停手 6 秒就退。席菈會去打其中一個拿棍子的。三個都倒下 → 席菈、彌夏各一句 →「待續／乾運河」→ 回標題。倒下重試：回到藥店門外，三個人滿血重來。請看：**看不看得出「綠霧是補品」**；丟毒瓶的站那麼遠會不會煩；打中人變快**有沒有感覺**；會不會太簡單 | 2 分 |

## 想看的事

（[`design/09`](archive/design/09-reboot-first-ten-minutes.md) 第 9 節）

- 30 秒內知不知道要把波克帶去南街。
- 3 分鐘時說不說得出「毒讓我回血、被打照樣受傷」。
- 守衛戰太長／太短。
- 死掉重來會不會卡住。
- 哪裡不知道要去哪。
- 哪一段、哪一個畫面質感最差。

## 效能量測（另外 1 分鐘）

在解壓資料夾開 PowerShell：

```
.\YumingCity.exe ++ --benchmark
```

約 35 秒後自動結束，結果在 `%APPDATA%\YumingCity\benchmark\bench-*.json`。把 JSON 內容貼到回覆區，並寫上**顯示卡型號與螢幕解析度**。目標：中階獨顯 1080p 中等畫質 60 fps（每幀約 16.7 ms）。

## 直接跳到某一段

```
.\YumingCity.exe ++ --level=frostbridge --rb-at=mist        # 毒霧
.\YumingCity.exe ++ --level=frostbridge --rb-at=guardian    # 南街守衛戰
.\YumingCity.exe ++ --level=frostbridge --rb-at=potion      # 藥箱
.\YumingCity.exe ++ --level=frostbridge --rb-at=market      # 梨攤前的艾妲
.\YumingCity.exe ++ --level=market --rb-at=arrive           # 地下市場：貨梯下來的第一眼
.\YumingCity.exe ++ --level=market --rb-at=shop             # 地下市場：藥店門口前
.\YumingCity.exe ++ --level=market --rb-at=board            # 藥店裡：櫃台前（已經跟彌夏講過話，可以直接按住互動鍵測）
```

這些是截圖用的旗標：畫面會停在那一段的固定位置（守衛會被停住不動），只適合看畫面，不適合拿來練打。用這些旗標（或 benchmark）開的遊戲存在另一個資料夾，**不會蓋掉你從標題玩到一半的進度**。
