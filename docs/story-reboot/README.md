## 使用者最新要求

- 第一章就不知道在玩什麼；開場吸引力優先於後面世界觀。
- 喜歡轉生重騎士、史萊姆、狀態異常的成長、能力巧用、冒險與反擊感。
- 可以有女角曖昧，主線一對一；不走收後宮。
- 不要再以鐘、失憶、犧牲為主軸；不要大量文言文或玄學名稱。
- 不要求重做引擎；目前已是 Godot，應沿用可用資產。
- 使用者授權的是劇情調整；本次不實作玩法、不聲稱已改善實際手感。
