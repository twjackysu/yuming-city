# 逆轉體質：20 種狀態
設計規格，未實作。所有藥劑均為虛構遊戲道具，不使用現實配方。

## 基本規則
- 開場兩個反轉欄位，中期三個、後期四個；只反轉已裝入欄位的狀態。首次中毒時自動解鎖並裝入「中毒」，不需玩家先懂配裝。
- 首次遇見未裝備狀態會留下可研究的紀錄；戰後透過安全測試解鎖，不允許中招瞬間自動獲得所有免疫。開場的中毒是能力覺醒特例，後續不反覆用特例救場。
- 戰鬥外換配置；戰中不能暫停後無成本切到任何反制。道具快捷欄可切換已帶的藥劑。
- 命中傷害和狀態分開：毒牙刺傷、火球撞擊、盾撞傷害仍有效；相應的持續中毒、燃燒、暈眩狀態才被反轉。
- 反轉發生在原負面效果生效前，不先扣一次再補回。未配置的效果正常處理。
- 同類效果不疊強度；採較強的一份，持續時間有上限。新來源可刷新，不能靠喝一百瓶永久增益。
- 自備藥效穩定、強度較低；特殊敵技可能較強，但仍有反轉上限。普通補給容易取得，支援試驗，不強迫刷素材。
- 反轉效果不是新的負面狀態，不再遞迴反轉。每個效果標記來源、類型、時間與強度。
- 技能不刪除記憶、劇情選項或存檔。死亡依正常檢查點重試。

## 時間停止的嚴格邊界
神明的技能是對區域內對象施加「時間停止」，不是宇宙所有物理過程絕對停止。第六章較弱的時間陷阱提前引入此規則。主角需研究後配置該欄位，才能在最終戰利用。

突破窗口內可躲、攻擊或破壞施法錨點；普通隊友仍停住。用完兩秒後停止行動，直到外層停時結束。此間回血、回魔、冷卻與藥效計時只按允許活動的兩秒推進；停住的其餘時間不免費結算。一次施法只觸發一次，不因反覆進出範圍刷新。

## 組合
- 續戰：中毒＋破甲。穩定回血與減傷，仍怕爆發。
- 高速吸血：流血＋麻痺。靠有效近戰續航，敵人脫離就失去回血來源。
- 法師：沉默＋魔力流失。快速施法與補魔，受冷卻、魔力容量及瞄準限制。
- 近身突破：恐懼＋燃燒＋沉重。衝近、附火、打出失衡；直接傷害仍致命。
- 自補盾：中毒＋治療封鎖。再生轉盾而非補血，有總盾量上限；取消禁療後再生恢復補血。
- 反擊：暈眩＋破甲＋睡眠。承受低傷控制招，回擊並保持體力；不該吃高傷招。
- 高階偵察：失明＋混亂。自己辨認隱敵，假身擾亂敵方視線；不能代替戰鬥。
- 最終戰：時間停止占一格；玩家在剩餘欄位選續航、輸出或防禦，而非自動裝全部。

## 上線節奏
首個十分鐘只做中毒反轉與虛構毒藥，讓玩家確實體驗差異。下一小段加入麻痺或暈眩其中一種。其餘是完整故事能力庫，不是要求首個版本一次做完二十種。
