## ★ 垂直切片：腐敗之森入口的 3 分鐘

現在有的：諾恩一個人走進森林 → 席菈等在瘴氣前面，問能不能一起去（兩個回答）→ 結伴 → 瘴氣（她戴防毒面具；諾恩中毒 → 回血，完整的反轉回饋）→ 兩人講四句 → 三隻劇毒史萊姆：劍是三下連段，每砍中一刀給自己中毒＋一層流血（越砍越快、越快越重）；席菈慌了射錯一瓶（重度麻痺＋防禦歸零 → 出手快 150%＋受傷少 80%）→ 一刀一隻清場 → 戰後對話（兩個回答）→ 「未完待續」。Jacky 11/14 玩過兩次：「還行」；相遇、面具、誤射、戰後對話、連段、一刀一隻這幾段他還沒玩過。

1. **砍下去要有感覺**（打擊感，動畫面的那一輪）：①揮劍的弧形劍光（平常暗紅鏽色、身上有反轉中的狀態時是金的；收尾那一刀最大）②三下的動作近看一次——`--burst-on=combo`，`BURST_RES=1920x1080`，側面（`--cam-yaw=90`）與玩家的鏡頭（背後）各一組，看手腕、劍的角度、第二下拉開時劍直直朝上好不好看 ③收尾那一刀自己的聲音（現在借 `blunt_weak`）④超頻時每一刀的打擊停頓要不要短一點（現在一刀 0.06～0.12 秒，出手 0.18 秒一刀時佔了三分之一）⑤程式人偶三下同一個姿勢（模型都在的時候看不到）。
2. **席菈再好一點**：①平常她在鏡頭後面看不到——頭上的話這時候不顯示，教學戰那兩句玩家可能根本沒看到（試：開打時往側面站、或她在鏡頭外時把話放在畫面邊上並標名字）②手弩的握把有沒有在手心（`Sera.CROSSBOW_ROT`／`CROSSBOW_OFFSET`；`BURST_RES=1920x1080 --burst-on=vial --cam-yaw=90`）③走過瘴氣要有反應（劇本：慌張地找防毒面具）④按鍵向她要藥（`SeraBrain.request()` 已經有，接上按鍵與第二種藥）⑤射藥與藥瓶碎掉的聲音現在借用 `whoosh`、`glass_clink` ⑥戰後對話的選項畫面拍一張看排版 ⑦相遇那一段加一點演出（她看著瘴氣猶豫的樣子、開口時鏡頭帶到她的臉）⑧防毒面具現在是程式拼的，玩的距離看得出來；要近看再排 Tripo（物件約 20 點）。
3. **森林再好看一點**（某一輪只動畫面時）：地面還是平的——加緩坡或土堤（先只做玩家走不到的外圍）；樹只有一種模型；史萊姆是紫的、場景也是紫的——給敵人一圈冷色的輪廓光或把牠的顏色往螢光綠偏；天空加星星與月亮；土丘的邊緣從側面近看還有一圈。改前先 `scripts/shots.sh forest --save-baseline`。
4. **要有人玩過才知道的**：連段的手感（0.45 秒內接得上嗎、第三下夠不夠重）；一刀一隻會不會太簡單（現在沒吃藥也只要 7 刀）；停手 5 秒後再砍，第一刀整個畫面又閃一次會不會太吵（太吵的話：自己的劍給的狀態只演小的——圖示翻面＋劍亮，不閃整個畫面）；被史萊姆連續撞時畫面一直閃；出手快 150% 手感會不會太飄；三個音效（`curse_sting`、`reversal_shatter`、腳步）沒有人聽過。
5. **戰鬥變長之後要處理的**（教學戰幾秒就打完，看不出來）：平常的藥瓶（×1.35）會幫重度麻痺（×2.5）續時間——同一種狀態只留最強的強度（做法：弱的來源不續強的時間，或強度跟著時間退）。「越快越重」讓傷害跟出手速度一起漲（最多 ×3.1），之後的敵人與 Boss 的血要照「有吃到增益」來定。
6. 切片好玩了再擴：森林完整版 → 祭壇 Boss → 公會大廳 → 城鎮（`13` 的場景表）。**做公會大廳（節點 1）的時候**：兩人在那裡先見到面（席菈縮在角落、被雷歐一起罵），森林口那段對話的自我介紹要跟著改短（D-280）。好感度現在只記數字（`sera.affinity`），還沒有地方看。

## 小事（改到的時候順手）

- `docs/design/04-architecture.md`「還沒整理的舊東西」那一節。
- 同一下上身兩種狀態時（一瓶藥、劍的第一刀），`curse_sting`（紫紅那一聲）會在同一幀播兩次，比平常大聲：`PlayerController._on_status_changed` 在回饋剛開始的那一幀（`reversal_cue.t == 0`）不要再播一次。劍接上自傷之後每場戰鬥的第一刀都會遇到。
- `statuses.json` 的 `boss_miasma`、道具 `sera_poison_vial`（`PotionBelt`）現在沒有場景在用：做 Boss、背包時用上，用不上就刪。
- `StatusEffects.attack_speed()` 的註解寫「畫面上寫快 36%」——畫面上沒有寫流血快多少（只有層數），改到那個檔的時候把註解改對；要不要在狀態列寫出百分比另外決定。
- 沒有經過瘴氣就先砍到東西（只有開發旗標 `--at` 做得到）時，第一次反轉的橫幅寫的是「中毒 → 回血」，沒提流血；正常玩一定先過瘴氣。
- 標題畫面的背景換成新遊戲的（現在是舊的鐘樓剪影）。
- 腳步聲沒有「土」的材質（森林現在借用雪的）。
- 席菈走路沒有腳步聲：接 `Puppet.footfall`（做法看 `PlayerController`，小聲一點）。
- 程式人偶（沒有模型時的替身）的步頻還是舊的算法，跟模型不完全一樣；模型都在的時候看不到。
- `scripts/shots.sh forest --fetch-baseline` 抓不到基準（`screens` release 沒有 `forest-*.png`）：看 CI 有沒有在上傳，沒有就把那個選項拿掉或補上傳。
