# 13　第一章實作計畫

劇本：[`../story/chapter-1.md`](../story/chapter-1.md)（Jacky 2026-11-14）。這份寫「怎麼做、先做什麼、用現有的什麼」。做完一項就在這裡打勾；細的待辦寫 NEXT。

## 核心循環（每個設計決定都回頭對這一句）

**故意去吃異常狀態 → 看它反轉成金色增益 → 用增益打爆敵人。** 陷阱、毒霧、詛咒裝備、席菈射來的藥水，都是「補給」。

## 反轉的回饋（劇本第三節，最優先做好）

吃到異常狀態：畫面邊緣閃紫／暗紅 → 0.3 秒後玻璃碎裂聲 → 轉成金色光效；HUD 上紅色 Debuff 圖示翻成金色 Buff 圖示。諾恩的劍在有反轉中的狀態時裂縫透金光。**做法**：`ReversalCue` 是唯一的時間軸，`StatusEffects.changed("start")` 觸發；之後的新狀態不用再寫回饋。

## 現況（2026-11-14 重新開始，D-273）

舊劇情的關卡與角色都砍了，只留通用底層（清單在 [`04-architecture.md`](04-architecture.md)）。現在標題按「新遊戲」會進**腐敗之森入口**：諾恩拿【瘴氣生鏽鐵劍】一個人走進來 → 席菈（【鍊金藥瓶手弩】）等在瘴氣前面，問能不能一起去，答應了才結伴 → 她戴上防毒面具，諾恩走進瘴氣中毒、反轉成回血 → 兩人講四句 → 空地上三隻劇毒史萊姆：劍是三下連段，每砍中一刀給自己中毒＋一層流血（越砍越快、越快越重）；席菈慌了射錯一瓶（重度麻痺＋防禦歸零 → 出手快 150%＋受傷少 80%）→ 一刀一隻清場 → 戰後對話（兩個回答，記好感度）。劇本節點 2 的每一拍都有了。Tripo 第二批 28 個模型都在 `art-inbox/tripo/`，大部分還沒接。
