# 03　美術與音效方向

> 狀態：**定稿 v1**（2026-11-08）。限制：loop 只能用程序生成或授權明確的素材，角色模型與動畫要等 Jacky 提供（`docs/ART_REQUESTS.md`）。所以質感主要靠**光、霧、後製、鏡頭、打擊感、聲音**，而不是貼圖細節。

## 一句話

**冬夜裡的一盞燈。** 冷藍、潮濕、霧重的石頭小鎮，只有鐘樓、油燈、薪火劍是暖色；暖光出現的地方就是故事重要的地方。

## 概念參考（2026-11-08，Jacky 提供）

`art-inbox/concepts/`（霜橋鎮冬夜、廢鐘樓、南街石拱、席菈與諾恩；AI 概念草案、未通過正式驗收，只當色彩與構圖參考）。從圖上拿來用的重點：

- **濕石板路**：燈光在濕石頭上拉出暖色倒影，是第一眼最有質感的地方 → 已用 `wet_cobble.gdshader` 做（D-036）。
- 房子是**半木構＋石牆**、屋頂厚雪、屋簷下掛油燈；街道會往遠處的鐘樓爬坡 → 外牆已用 `half_timber.gdshader` 做（一樓石牆、樓上灰泥＋木框斜撐，D-039），門口掛燈已加；爬坡還沒做。
- 霧把遠景壓成一層層的灰藍剪影；鐘樓在霧後面透出暖光。
- 角色：諾恩是補丁長外套＋圍巾、右臂木板夾傷、手拿鐘錘；席菈是破舊的白短斗篷、扛一把很寬的斷劍。程序人偶之後照這個輪廓調。

## 色彩

| 用途 | 顏色 | 說明 |
|---|---|---|
| 夜空、霧、陰影 | `#05080F`～`#17202E` | 冷、低飽和，標題畫面為基準 |
| 雪、石面受光 | `#A9B6C6` | 偏藍灰，不用純白 |
| 油燈、鐘樓燈 | `#F2B86B` | 唯一的暖色主光 |
| 九息 | `#CFE8FF`＋淡金邊 | 去飽和世界中唯一發光的東西 |
| 薪火劍 | `#FF7A2E`→`#FFD27A` | 最強的暖色，只在關鍵演出 |
| 灰、化灰 | `#6E6A66` | 暖灰，與冷霧區隔 |

規則：同一畫面暖色面積不超過 15%；介面文字用 `#E8E2D6`（暖白），不用純白。

## 光與霧（Godot Forward+）

- **WorldEnvironment**：Filmic／AgX tonemap、自動曝光關閉（手動控制夜景亮度）、Glow（bloom）只讓暖光與九息溢出。
- **體積霧**（Volumetric Fog）：密度 0.02～0.04、albedo 偏藍；油燈與鐘樓燈開 `volumetric_fog_energy` 讓光柱可見。畫質「低」關閉，改用深度霧。
- **全域光照**：預設用 **VoxelGI**（霜橋鎮範圍小、可烘焙）；SDFGI 作為「高」以上選項，實機量測後再定。低畫質只用環境光＋反射探針。
- **陰影**：月光（DirectionalLight3D）冷色、柔和；油燈 OmniLight3D 只開少數幾盞的陰影（每畫面 ≤ 4）。
- **後製**：SSAO（中以上）、SSR（高以上，濕石板）、輕微色差與暗角、底片顆粒（可關）；九息時用全螢幕 shader 去飽和＋邊緣扭曲。

## 環境與道具（程序生成優先）

- **建築**：CSG／程序 mesh 拼出石屋、木樑、拱門；三平面投影（triplanar）程序材質（石、木、雪），用 noise 疊出磨損與積雪，不依賴貼圖。
- **雪與霧粒子**：GPUParticles3D；落雪跟隨鏡頭、地面積雪用 decal＋頂點色。
- **鐘樓**：作為全鎮的地標與光源，從任何街道都看得到它的燈。
- **九息物件**：損壞態是斷裂的 CSG；重現時用 dissolve shader 從灰燼往上長出，化灰時反過來並噴灰粒子。
  - 現況（11/8）：按住預覽＝`restore_ghost.gdshader` 冷光輪廓隨按住進度從地面往上長（D-046）；重現後＝鎮上石牆 shader＋石縫冷光、心跳時亮一下（D-043）——要看得出「是原本那座石拱」，不是發光的板子。
- **燃燒劍**（D-042）：劍身燒紅＋橘色 OmniLight＋往上飄的火星，暖光打在整條濕石板街上；只在提前斬鐵架與結尾斬倒送葬者兩個時機出現（「暖光出現的地方就是故事重要的地方」）。被斬斷的鐵架斷口燒紅。

## 角色（替代方案）

- 在 Jacky 提供有骨架的模型前：程序生成的**人偶**（膠囊＋分段肢體，Skeleton3D 由程式建立），用程式動畫（步行循環、揮擊、閃避的關節曲線）＋布料感的披風（SoftBody 或 shader 擺動）。
- 剪影優先：諾恩＝長外套＋鐘錘；席菈＝短披風＋直劍＋右手手套；灰巡者＝前傾、胸口發光鐘盤；送葬者＝背後巨大鐵架。剪影在霧中也要認得出來。
- 臉部不做特寫；對話用越肩鏡頭＋字幕＋肢體動作，避開人偶臉的限制。

## 鏡頭與打擊感

規則在 [`02-gameplay.md`](02-gameplay.md) 的「鏡頭」。美術面補充：

- 命中：hit stop＋白色閃光邊緣（0.05 秒）＋火花／冰屑粒子＋低頻「咚」。
- 打弱點成功：0.09 秒停頓、鏡頭微推、敵人弱點處爆出暖色碎光。
- 前兆：姿勢之外加**地面霜紋**（decal，形狀＝攻擊範圍）＋聲音提示；色盲友善（形狀與聲音都能分辨，不只靠顏色）。

## 介面

- 攻略筆記本是母題：選單像手寫筆記頁（紙張紋理用 shader 產生），日記的「被剪掉的記憶」是整齊的空白剪口。
- 字型：標題 Noto Serif CJK TC（明體）、介面 Noto Sans CJK TC（D-010）；英文用同一家族的拉丁字形。
- HUD 極簡：諾恩生命、席菈狀態（體力、手傷）、指令提示只在戰鬥中出現；探索時幾乎沒有 HUD。

## 音效與音樂（程序生成）

用 Python（numpy／scipy）在建置時合成 wav，放到 `assets/generated/audio/`（不進 git，D-004）：

| 聲音 | 合成方式 |
|---|---|
| 鐘聲 | 加法合成：非整數倍泛音（1、2.4、3.0、4.5、5.9）＋長衰減＋輕微走音；九聲逐漸變低沉 |
| 心跳（九息） | 低頻正弦脈衝雙拍（lub-dub）＋低通；第九聲最大 |
| 風雪 | 粉紅雜訊＋帶通掃頻＋陣風包絡 |
| 腳步（雪、石） | 短雜訊脈衝依材質濾波，隨機音高 ±5% |
| 打擊、鐵鏈 | 雜訊＋金屬共振（梳狀濾波） |
| 化灰 | 顆粒合成（grain）由高往低 |
| 音樂 | 先用長音鋪底（drone）＋鐘聲動機；正式配樂列在 ART_REQUESTS |

混音：Master／Music／SFX／Voice／UI 匯流排；九息期間 SFX 低通＋Music 壓低，讓心跳最清楚。
- 現況（11/10，D-183）：`RestoreMix`——重現中 SFX 低通 20 kHz → 900 Hz（0.25 秒進入、0.9 秒放開）、Music -8 dB；心跳走自己的 `Heart` 匯流排（不被悶住，音量跟著「音效」）。

配樂放在哪裡（D-185）：**環境音為主，配樂只放在「打完之後安靜下來」的地方**，打的時候、探索的時候都不放（讓重現的心跳與鐘聲是最清楚的聲音）。
- 現況（11/10）：標題（`title_theme`，D-181）、切片收束（車隊過去、回梨販攤：`aftermath_theme`，D-185）。
- 候選（照同一條判斷再決定）：第一部前半的結尾卡／感謝試玩頁、第 1 章柯德家晚餐之後走在白晝城。

## 第一眼質感檢查（每次動畫面都要問）

1. 截圖縮成手機大小，還認得出主角、席菈、敵人、暖光焦點嗎？
2. 有沒有一個地方是「暖光＋霧」的剪影構圖？
3. 九息發動那一刻，是不是整個畫面最亮、最安靜的瞬間？
4. 去掉 HUD，畫面還能說故事嗎？
