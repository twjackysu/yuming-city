# 02　玩法規則（現在程式裡有的）

劇本在 [`../story/chapter-1.md`](../story/chapter-1.md)，要做的東西在 [`13-chapter-1-plan.md`](13-chapter-1-plan.md)。這份只寫**已經做出來、程式照著跑**的規則；加了新規則就補在這裡，數值寫在 `game/data/`，這裡不抄數字。

## 核心循環

**故意去吃異常狀態 → 看它反轉成增益 → 用增益打爆敵人。** 陷阱、瘴氣、詛咒裝備、席菈的失敗作藥水都是補給。

## 異常狀態與反轉（`StatusEffects`、`data/status/statuses.json`）

- 同一種狀態身上只有一份：新來源比較強就換強度；時間取剩下的與新的較長者，不超過上限。**會疊的狀態**（資料表有 `stack_max`：流血）再上一次是把強度加上去，到上限為止。
- 四類：`dot`（每秒扣血；反轉＝每秒回血，有上限）、`action`（不碰生命；沒反轉＝不能出手，反轉＝出手加速）、`guard`（不碰生命；沒反轉＝受到的直接傷害變多，反轉＝變少，有上限、不會無敵）、`bleed`（強度是層數；沒反轉＝每秒扣血，反轉＝每層出手再快一點）。現在有**中毒**（dot）、**麻痺**（action）、**防禦歸零**（guard）、**流血**（bleed）。
- 出手加速是加起來的：麻痺的倍率＋流血每層的加成（出手快 150% 再疊三層流血，就是快 186%）。
- **落在諾恩身上的全部反轉**（【逆理之器】，`StatusEffects.reverses`）：不用解鎖、不用裝、沒有數量限制、沒有代價；其他人（敵人、NPC）照原樣吃。反轉發生在扣血之前（不先扣再補）。
- 狀態照原樣存檔（讀檔不補滿、不清掉）；暫停、對話中不計時。
- 來源寫在資料表的 `sources`（瘴氣、史萊姆的撞擊、席菈的藥瓶…），場景只說「套用哪個來源」。一個來源可以再帶一個（`also`）：一瓶藥兩種狀態一起上身、一起反轉。
- 加新狀態：`statuses.json` 加一筆＋翻譯 key＋`StatusHud` 的圖示；新的種類（不是 dot／action／guard／bleed）才要動 `StatusEffects`。
- 狀態列：每種狀態一格；會疊的狀態在圖示右上角寫現在幾層。

### 反轉的回饋（`ReversalCue`，每一種狀態都走同一條）

- 狀態**新上身**的那一刻開始（同一種狀態刷新不重播——站在瘴氣裡每 0.25 秒刷新一次，不會一直閃）。
- 畫面邊緣亮紫紅＋一聲往下沉的「嗚」→ 0.3 秒 → 邊緣像玻璃一樣裂開、一片片掉＋碎裂聲接三聲往上的鐘音 → 邊緣金光慢慢退；同一刻諾恩身上噴一團金色光點、鏡頭輕震、狀態列的圖示從紅的翻成金的（旁邊彈一圈金光，字從「中毒」變成「中毒 → 回血」）。兩種狀態同時上身（一瓶藥帶兩種）只演一次，兩個圖示一起翻。
- 顏色的語言：**紫紅＝壞東西上身、金＝反轉成增益**（圖示、字、光都是金）；綠只留給「生命正在回」（生命條的綠段、身邊的綠光點）。
- **劍的金光**：身上有任何反轉中的狀態時，諾恩的劍蓋一層金光（碎裂那一下最亮，之後退到平常的亮度；狀態沒了就暗掉）。
- 時間都在 `ReversalCue` 的常數；讀檔時身上已經有的狀態直接是翻好的，不再演一次。

## 戰鬥

- **移動與腳步聲**：平常是小跑（3.4 m/s，跑的動作），Shift 衝刺（5.8 m/s）。腳步聲在腳落地的那一刻播（`Puppet.footfall`），不照距離算——聲音跟畫面上的腳一定對得上。閃避、被推開、騰空時不出聲。
- **諾恩**（`PlayerController`）：出手是前方扇形的一刀，命中有打擊停頓與鏡頭震動；出手會往瞄的敵人滑一小步；提早按的鍵會記住一小段時間；挨打有短硬直。敵人跪著時打他傷害與失衡加倍。數值在 `tuning.json` 的 `noen`。
- **三下連段**：往下劈 → 橫掃 → 收尾的重劈（比較痛、掃得比較寬、夠得比較遠；`noen.finisher_*`）。收招後 `combo_window` 秒內再出手就接下一下；停手太久或挨打就從第一下重來。三下一樣長，差別在動作、傷害與範圍。
- **【瘴氣生鏽鐵劍】**（`PlayerController.on_hit_source`）：每**砍中**一刀給自己微弱中毒＋一層流血——對諾恩是慢慢回血（也在累積「釋放」的秒數）＋越砍越快。揮空不算。停手 5 秒流血就退。
- **出手越快砍得越重**（`noen.haste_damage`）：出手被加速多少，那一刀的傷害就多多少。流血疊滿多六成；吃了席菈拿錯的那一瓶（出手 ×2.5）一刀就能砍倒一隻劇毒史萊姆。
- **出手會自動轉向最近的敵人**（前方 `lunge_seek` 公尺內；鎖定時打鎖定的）；倒下的不算。
- **釋放**：把身上的**中毒**一次用掉，炸周圍的敵人；傷害＝用掉的秒數 × 係數（有上限）。放完就沒有回血了——留著慢慢補，還是炸出去。
- **敵人**（`EnemyBrain`＋`EnemyActor`）：追 → 前兆 → 出招 → 破綻 → 追；失衡滿了跪地；被諾恩打中會後仰，連續被打幾下之後變紅硬撐（只扣幾成、不再後仰）直到出完一招。同時只有 `crowd.attack_slots` 個敵人能出手，其他人在外圈等。難度（故事／標準／困難）改敵人傷害與前兆長度。
- **劇毒史萊姆**（`Slime`）：慢慢靠近、壓扁蓄力、往前撲；撞到除了傷害還上中毒——對諾恩是回血。
- 倒下：從最近的檢查點重來（重讀自動存檔，生命至少一半）。

## 席菈（`Sera`、`SeraBrain`、`SeraVial`；數值在 `tuning.json` 的 `sera`）

- **結伴之前**（旗標 `ch1.sera_joined`）：她站在原地等，不跟、不射；諾恩走近會轉過來看他。腐敗之森入口：開場只有諾恩，她等在瘴氣前面，走到她面前她開口問能不能一起去（`ch1_sera_joins`，兩個回答），答應了才結伴。
- **她沒有諾恩的體質**：瘴氣對她是真的毒，所以離瘴氣邊緣 `MASK_MARGIN` 內就戴上防毒面具，離開 `MASK_OFF_DELAY` 秒才拿下來。玩家要看得出「她為什麼沒事」——之後的毒物（陷阱、Boss 光環）她要嘛躲開、要嘛有看得到的防護，不能默默沒事。
- **跟**：離諾恩超過 `follow_far` 就跟上，走到 `follow_near` 以內才停；落後太多用跑的；被甩得太遠（卡住）直接出現在諾恩後面。對話中、諾恩倒下時站著。不擋路，敵人不打她。
- **射**：諾恩 `threat_range` 內有活著的敵人才射——開打後 `first_vial_delay` 秒來第一瓶，之後每 `vial_interval` 秒一瓶；每瓶先舉弩瞄 `aim_time` 秒（這時候不走路）。敵人都倒了就把倒數退回「第一瓶」。
- **藥瓶**一定會中（她瞄的是諾恩的背）；砸到就套用資料表的來源，反轉的回饋照上面那一條自己播。平常是 `sera_paralysis_vial`（麻痺 → 出手加速）；關卡可以換下一瓶（`Sera.vial_source`）。
- 結伴之後讀檔，她站在諾恩左前方；第一次在瘴氣裡反轉之後兩人講幾句（`ch1_forest_gate`，只講一次；先被史萊姆撞到中毒的話不講）。
- **教學戰（腐敗之森入口）**：第一瓶是她慌了拿錯的 `sera_panic_vial`（重度麻痺＋防禦歸零 → 出手快 150%＋受傷少 80%；出手快了每一刀也重 150%，史萊姆一刀一隻）——舉弩時頭上一句、砸中後一句，畫面中間寫反轉成什麼；只演一次（倒下重來會再演）。三隻史萊姆都倒了之後她開口（`ch1_after_slimes`）：兩個回答，各加不同的好感度（旗標 `sera.affinity`）。
- 頭上的話（`Hud.show_bark`）：講的人不在畫面裡就不顯示；會讓開畫面中間那兩行字。

## 任務、指引與存檔

- 任務是資料（`data/quests/*.json`）：每個階段有目標文字、操作提示（選填的 `hint`）、目標指引的位置、檢查點、完成條件（旗標）。關卡只負責設旗標。
- **玩家隨時知道現在要幹嘛**（Jacky 11/14 玩過：「不知道要幹嘛，畫面也沒有什麼指引」）：左上的目標一直在畫面上，不會淡掉；下面一行寫這個階段用得到的按鍵（照現在用的是鍵鼠還是手把）；目標的位置有菱形與距離。
- **內容到底要講**：主線全部做完時，中央跳「未完待續——目前的內容到這裡」，左上改寫「目前的內容到這裡，後面還在做」。每加一段劇情，這句話自然往後移，不用改。
- 進入有檢查點的階段就自動存檔；標題的「繼續」讀這一份。存檔資料夾 `user://saves`。

## 用詞

玩家看到的字要白話：能力、系統、狀態、按鍵名用「它做什麼」來命名（中毒／回血／反轉），第一次出現就用一句完整的話講清楚效果，數字直接寫。對白用現代口語。人名、地名、怪物名可以是名字。英文同一套規則。測試會擋掉幾個以前用過的難懂詞（`tests/unit/test_i18n.gd`）。
