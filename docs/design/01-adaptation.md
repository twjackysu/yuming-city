# 01　改編：小說 → 遊戲

> 狀態：**初稿**（2026-11-07）。先把垂直切片需要的部分定下來。全書已讀完並整理成 [`00-story-digest.md`](00-story-digest.md)；全篇章節對應、角色弧線與後續章節選擇下一輪補齊。原作不修改，遊戲可以自由改編。

## 改編原則

1. **代價是核心情感**：原作每一次拯救都要有人付出（諾恩付記憶、席菈付肌腱）。遊戲裡的能力都要讓玩家看得到、選得到、付得起，而且付了之後故事記得。
2. **主角不是最強的人**：諾恩是「弔鐘人」，傷害低；他的強項是前世攻略的知識（看穿弱點與前兆）和九息。戰鬥設計要讓「看懂、喊對、站對位置」比數值更重要。
3. **關係有份量**：席菈不是跟班。她有自己的職責（王室巡界隊、可以當場處決破壞封印的人）、自己的代價（薪火劍）與自己的底線（「沒事」是她最危險的一句話）。
4. **少而精**：每章只取能變成「可玩、可選、可感受」的段落，其他用過場、物件與對話帶過。

## 垂直切片：《霜橋鎮的第九聲鐘》（第一部第一、二章）

| 原作段落 | 遊戲化方式 | 類型 |

| 水晶上的職業：弔鐘人，九息，永久失去記憶 | 教學：第一次看到「可保存」提示時，同一個介面同時顯示代價 | 系統 |

| 灰巡者：弱點在左膝，諾恩喊、席菈斬 | 協作戰鬥教學：諾恩「看穿」弱點，下指令讓席菈攻擊；諾恩自己閃避、牽制 | 戰鬥 |
| 「右轉」：喊出攻擊前兆 | 讀招教學：敵人前兆明顯，及時喊出（指令）可讓席菈閃開並反擊 | 戰鬥 |

| 「霜橋鎮死了三十一個人」、鐘樓底下還有心跳 | 收束：死者名單（救援成果反映在名單上）、走向下城入口（梨販家地窖）的決定 | 演出＋抉擇 |

### 切片中的選擇與旗標（初稿）

- `slice.rescued_count`：救援段救出的人數（影響死者名單與艾妲的態度）。
- `memory.arch_father_last_talk`：是否付出石拱的記憶。原作必付；遊戲提供「不保存」的替代解（硬撐、讓席菈更早用薪火劍），代價轉嫁給席菈或車隊，讓選擇有意義。
- `sheila.kindling_used_early`：如果玩家拒絕九息，席菈提前燒劍，之後她的手傷更重（後續章節的關係與戰鬥會記得）。
- `slice.told_truth_about_bell`：席菈問「你敲了幾下」時是否說實話（原作說實話）。
