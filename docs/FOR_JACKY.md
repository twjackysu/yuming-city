4. **角色模型**（接入點 D-041；進度照你的 `docs/ART_DELIVERY_STATUS.md` 追）：都還在 `art-inbox/studies/`，照 README 沒有接進遊戲。最新意見：**席菈披肩（11/10 10:25）**：從圍巾變成蓋住雙肩的短披肩，方向對了，走路也沒有穿插，謝謝。`cape_close_preview` 裡它還像一個硬殼：肩膀兩側往外撐成圓圓的泡泡袖、下緣是一整圈水平的線、整片接近純白、幾乎沒有陰影和皺褶——建議讓它順著重力蓋過上臂（兩側下緣低一點、不要往外翹）、從領口往下幾道垂直的大皺褶、下緣不規則一點，顏色壓到米灰（例如 #c8c2b5）、粗糙度高一點，暖燈下才不會變成發亮的白塊。**諾恩 idle（10:36）**：左臂自然下垂、手指收攏，好很多；手掌還有一點往前翻（掌心朝鏡頭），轉成掌心朝大腿會更放鬆。**諾恩 run（10:48）**：左臂收在身側、手半握，看起來真的在跑了，謝謝；`run_preview` 大衣下襬裡面（兩腿之間、膝蓋上方）露出一塊淺色，像內襯或皮膚面片穿出來，有空看一下。**席菈大劍（15:35）**：收到 35 cm 之後跟背差不多寬、斷口那端收窄，比例對了；暖燈下也看得出是金屬（斜刃有一道亮邊），謝謝。剩兩點：`blade_night_preview` 整片劍面在暖燈下是均勻的金銅色（金屬的底色會染到反光，偏暖的底色＋暖燈＝鍍金感）——底色改成偏冷的中性灰（例如 #7d8186），暖燈只留在高光；`blade_preview` 棚光下劍面上的「刮痕」是一顆顆白色斑點，看起來像落雪或噴漆，改成沿著劍身方向的細長刮痕、氧化用暗色會比較像鐵。護手頂面一條純白的亮邊（之前送葬者橫桿也有）可以壓暗一點。棚光的 `preview.png`（兩個人都是）雙腳看起來比影子高一截，如果只是鏡頭角度就忽略。送葬者的六個關節定位點、諾恩三材質都符合需求。要試接時放成 `art-inbox/characters/<id>/<id>.glb`（席菈 `sheila/sheila.glb`），CI 用你的 `check_character_glb.py` 檢查，**通過就自動換掉程序人偶**；動作名稱照 `art-inbox/README.md`。用到 ACCAD／CMU 動捕時，`docs/CREDITS.md` 會照你寫的授權與致謝原文加上去。 **新版最需要的是送葬者**：追擊段牠在 6～7 m 外只是一個深色的小人影（程序人偶的極限），模型過關後這一段和南街守衛戰受益最大。
