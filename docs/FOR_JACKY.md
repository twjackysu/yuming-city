# 給 Jacky

只列需要你處理或想聽你意見的重點；處理完的會刪掉。沒回覆的意見題，loop 會照預設做。

1. **怎麼玩**：到 [latest](https://github.com/twjackysu/yuming-city/releases/tag/latest) 下載 zip → 解壓 → 雙擊 `YumingCity.exe` → 標題按「**新遊戲**」，約 20 分鐘玩到「待續」（現在的結尾在**走出彌夏的店、打贏護腕商人帶來的三個人之後**）。**之前已經玩到「待續」的話直接按「繼續」**：會站在藥店裡的櫃台前，**走出店門**就是新的一段。每一段要做什麼看 [playtest.md](playtest.md)。
2. **戰鬥場：多了一個鍵「釋放」——把身上的毒炸出去**（11/13 第 97 輪更新）。到上面的 latest 下載 → 標題按「**戰鬥場**」，按下去就開打。**這一輪做的是你同意的那一件事：逆轉體質不再是站著就有的數字，要你自己按。** 第一波後面站著一個丟毒瓶的：綠霧落在你腳邊 → **站在裡面**，生命條下面「中毒 → 回血」後面的秒數會一直漲（那一列後面會寫「滑鼠右鍵：炸出去 多少」）→ **按滑鼠右鍵（手把 Y）**：周圍 3 m 的敵人每個扣「秒數 × 8」（最多 80；一般敵人 70～120 血），腳邊一圈綠環擴出去，環停的地方就是炸得到的地方。放掉之後身上的毒就沒了。留著毒只會慢慢回血（比以前少很多——以前站著亂按就會贏）。**「看穿」從滑鼠右鍵搬到鍵盤 V**（手把 LT 不變）。其餘跟上一輪一樣：敵人五下以內倒、一波 6～8 個人一個接一個來；他整個人變紅的時候打不斷、也打不痛——閃（空白鍵／手把 B）；你五下倒；提早按 0.2 秒內都算。第 4 波是頭目，牠噴的綠霧也可以拿來養、拿來炸。機器人的數字：前三波站著不動 12 秒左右倒、一直按攻擊（不按釋放）贏 55%／40%／10%、每一下都閃得掉又會放的全贏（一波 17～20 秒）。**還沒做的**：釋放的時候人沒有動作（只有特效與聲音）；麻痺還不能放；諾恩的碎念與旁人的反應還沒有；沒有連段；人物還是原本的人偶。**只想知道一件事：打起來最怪的是鏡頭、移動、還是出手？**（在下面「回覆」寫一個詞就好——回哪一個我就改哪一樣；都不怪、只是無聊，也請直說。）到現在還是沒有人玩過改過的版本——機器人量得出難不難，量不出爽不爽。劇情那 20 分鐘的戰鬥沒有動（釋放在劇情裡按了沒有反應）。方向與規格在 [design/11](design/11-combat-first.md)。
3. **你說「不知道在玩什麼」——我的判斷**：故事的點子沒問題（你聽的時候覺得當動漫會有趣），是我做進遊戲的方式有問題。原文好笑的三樣東西——諾恩自己的碎念、旁人看他像看瘋子的反應、「每個敵人都是新的配裝材料」——遊戲裡一樣都沒有，只剩走路和一本正經解釋玩法的對話。接下來試玩版只講一句話：**別人躲的壞東西，是你的配裝材料**，而且要你用操作做到，不靠文字說明。（想問你的那一題在上面第 2 項。）
4. **人物不好看**：戰鬥的數值修好之後，我會先查授權完全開放（CC0）、帶動作的現成人形能不能用，在戰鬥場換一個角色，放一張「現在的人偶｜現成人形」的對照圖給你一句話決定（風格會偏低面數）。你自己做的模型過關就優先用你的——**角色模型**（接入點 D-041；進度照你的 `docs/ART_DELIVERY_STATUS.md` 追）：都還在 `art-inbox/studies/`，照 README 沒有接進遊戲。最新意見：**席菈披肩（11/10 10:25）**：從圍巾變成蓋住雙肩的短披肩，方向對了，走路也沒有穿插，謝謝。`cape_close_preview` 裡它還像一個硬殼：肩膀兩側往外撐成圓圓的泡泡袖、下緣是一整圈水平的線、整片接近純白、幾乎沒有陰影和皺褶——建議讓它順著重力蓋過上臂（兩側下緣低一點、不要往外翹）、從領口往下幾道垂直的大皺褶、下緣不規則一點，顏色壓到米灰（例如 #c8c2b5）、粗糙度高一點，暖燈下才不會變成發亮的白塊。**諾恩 idle（10:36）**：左臂自然下垂、手指收攏，好很多；手掌還有一點往前翻（掌心朝鏡頭），轉成掌心朝大腿會更放鬆。**諾恩 run（10:48）**：左臂收在身側、手半握，看起來真的在跑了，謝謝；`run_preview` 大衣下襬裡面（兩腿之間、膝蓋上方）露出一塊淺色，像內襯或皮膚面片穿出來，有空看一下。**席菈大劍（15:35）**：收到 35 cm 之後跟背差不多寬、斷口那端收窄，比例對了；暖燈下也看得出是金屬（斜刃有一道亮邊），謝謝。剩兩點：`blade_night_preview` 整片劍面在暖燈下是均勻的金銅色（金屬的底色會染到反光，偏暖的底色＋暖燈＝鍍金感）——底色改成偏冷的中性灰（例如 #7d8186），暖燈只留在高光；`blade_preview` 棚光下劍面上的「刮痕」是一顆顆白色斑點，看起來像落雪或噴漆，改成沿著劍身方向的細長刮痕、氧化用暗色會比較像鐵。護手頂面一條純白的亮邊（之前送葬者橫桿也有）可以壓暗一點。棚光的 `preview.png`（兩個人都是）雙腳看起來比影子高一截，如果只是鏡頭角度就忽略。送葬者的六個關節定位點、諾恩三材質都符合需求。要試接時放成 `art-inbox/characters/<id>/<id>.glb`（席菈 `sheila/sheila.glb`），CI 用你的 `check_character_glb.py` 檢查，**通過就自動換掉程序人偶**；動作名稱照 `art-inbox/README.md`。用到 ACCAD／CMU 動捕時，`docs/CREDITS.md` 會照你寫的授權與致謝原文加上去。 **新版最需要的是送葬者**：追擊段牠在 6～7 m 外只是一個深色的小人影（程序人偶的極限），模型過關後這一段和南街守衛戰受益最大。
5. **之後才需要、而且只有你能做的**：Steamworks 帳號／App ID／商店頁（Steam 文案與素材照你的指示暫緩）；實機 benchmark（指令在 [playtest.md](playtest.md)，附顯示卡型號與解析度）——試玩時順便測一次就好。
