# 首個可玩關卡：霜橋鎮的第九聲鐘

目標：20–30 分鐘、可從頭到尾完成的 Windows 打包版本。以下為驗證計畫，尚未實作。

## 遊玩流程

1. 在小範圍霜橋鎮與居民互動，認識梨販與環境，建立崩塌前的對比。
2. 敲鐘引發崩塌，玩家撤離並救援居民。
3. 與席菈首次合作，學習移動、閃避、近戰及指示同伴。
4. 面對送葬者，將石拱重現九秒，讓傷者車隊通過。
5. 呈現記憶代價與事後對話，收束到前往地下城的決定。

## 必須驗證

- 一個普通敵人、一個精英敵人，一名可協作同伴，戰鬥讀招清楚。
- 九秒能力具有明確預覽、代價、視聽回饋及結束狀態；讀檔不會重複付費或卡死。
- 鍵鼠與手把皆能完成；字幕、音量、基本畫質及暫停可用。
- 存檔 / 讀檔、死亡重試、過場跳過和任務恢復可用。
- 在選定 PC 實機達到效能目標；測量打包版本，而不只看編輯器。
- 有一小段代表最終美術與音效方向的場景，供估算完整製作成本。

## 本階段邊界

不做多人、手機版、完整開放世界、整座城市經營、全篇配音或全部 44 章。完成驗證後，再決定正式遊戲的章節數、可玩時長、團隊與預算。
