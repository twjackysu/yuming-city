# 餘命城 / Yuming City

以原創小說《餘命城》改編的 PC 單機敘事動作 RPG。第三人稱、章節式，核心是「重現」：讓毀掉的東西回到原本的樣子 9 秒，代價是永遠忘掉一段記憶。

> 目前狀態：**階段 1：垂直切片（核心框架、戰鬥與重現完成；霜橋鎮白盒已能從新遊戲走到切片結尾，接著補段落細節與打磨）**。「新遊戲」進入霜橋鎮：在廣場和梨販說話 → 爬上鐘樓親手敲九下，第九聲北街陷落 → 搬開瓦礫救出受困者 → 席菈替你夾上木板，問「你敲了幾下」→ 和她一起打倒灰巡者 → 在南街護送傷者車隊對抗送葬者，鐵架擲來時決定要不要「重現」倒塌的石拱擋下（代價是永遠忘掉和父親的最後一次對話，日記裡那段會被整齊剪掉）→ 回到梨販攤，走進地窖。首個可玩切片《霜橋鎮的第九聲鐘》預計 2026-11-30 完成。

## 試玩

- **Windows**：到 [Releases → latest](https://github.com/twjackysu/yuming-city/releases/tag/latest) 下載 `YumingCity-windows-x64-*.zip`，解壓後執行 `YumingCity.exe`。這是每次推送到 `main` 自動建置的開發版。路線、兩條結局分支與想聽的感想見 [試玩指南](docs/playtest.md)。
- **用 Godot 開啟原始專案**：安裝 [Godot 4.7.2 stable](https://godotengine.org/download/archive/4.7.2-stable/)（標準版，不是 .NET 版），在專案管理員「匯入」`game/project.godot`。Linux 可以直接執行 `scripts/get-godot.sh` 下載並驗證同一版本。

## 操作方式

| 動作 | 鍵鼠 | 手把 |
|---|---|---|
| 移動／鏡頭 | WASD／滑鼠（點一下畫面鎖定滑鼠） | 左／右搖桿 |
| 衝刺 | Shift | 左搖桿按下 |
| 閃避（前滾） | Space | B |
| 揮擊（鐘錘下劈） | 滑鼠左鍵 | X |
| 看穿（按住：已知弱點與招式） | 滑鼠右鍵 | LT |
| 鎖定目標 | 滑鼠中鍵 | 右搖桿按下 |
| 指令席菈：打弱點／閃開／守住 | Q／E／R | 十字鍵 上／右／下 |
| 重現（靠近可以重現的東西，按住 1 秒：讓它回到倒塌前的樣子 9 秒，代價是一段記憶） | V | Y |
| 鎖定中換目標 | 滑鼠左右甩 | 右搖桿左右撥 |
| 互動／對話下一句／敲鐘（按住跳過） | F | A |
| 日記（記憶條目） | Tab | View／Back |
| 暫停 | Esc | Start |
| 效能 overlay | F3 | — |

戰鬥：繞到灰巡者左側打得到左膝；牠出完招的破綻或跪地時喊「打弱點」，前兆後段喊「閃開」。送葬者舉起鐵架時，走到南街石拱旁按住 V／Y 一秒「重現」石拱（按住時畫面右側會出現你要付出的那段記憶），不用的話席菈會提前燒自己的劍。被抓住時連按閃避掙脫；席菈倒下 8 秒內走過去按 F 拉她起來。想直接練習：在解壓資料夾開 PowerShell，執行 `.\YumingCity.exe ++ --level=frostbridge --convoy`（霜橋鎮南街的送葬者戰，加 `--phase2` 從第二階段開始）或 `++ --level=sandbox --enemies`（沙盒裡的灰巡者）。

選單：方向鍵／滑鼠或手把十字鍵選擇，Enter／A 確認，Esc／B 返回；設定裡左右鍵切換選項。所有按鍵都可以在「設定 → 按鍵設定」重新綁定（暫停鍵與移動搖桿除外）。戰鬥、指令、重現等完整操作見 [docs/design/02-gameplay.md](docs/design/02-gameplay.md)，會隨切片陸續加入。

## 目前完成的範圍

- Godot 4.7.2 專案骨架（`game/`），Forward+ 渲染，Windows 預設 D3D12
- 繁中＋英文在地化，所有玩家可見文字都走翻譯 key
- 自動測試（腳本型別檢查、i18n 規則、主線流程、只用手把走完切片各段：敲鐘、救援、灰巡者、送葬者戰、暫停與按鍵設定）與 GitHub Actions 自動匯出 Windows／Linux（匯出版會實際開到霜橋鎮截圖驗證）
- 資料驅動任務系統、版本化存檔（自動存檔、死亡重試）、重現（九息）狀態機；主線流程測試真的換場景從新遊戲走到切片結尾，每個檢查點都重來一次驗證任務恢復（兩條路線）
- 第三人稱移動與越肩鏡頭、霜橋鎮白盒（廣場、主街、北街、鐘樓、南街石拱、路口；體積霧、暖光、濕石板路與水窪倒影、半木構房子與石牆、門口掛燈、往鐘樓爬坡的石階、靜態幾何合併）、程序人偶與程式動畫；正式角色模型一放進 `art-inbox/characters/` 通過收件檢查就自動換上
- 切片各段落：梨販（南街石拱的回憶）→ 敲鐘九下 → 北街救援（按住搬瓦礫）→ 席菈登場對話（說實話／說謊）＋灰巡者（看穿教學）→ 南街送葬者戰 → 艾妲（死者名單依救援與護送結果）與地窖
- 日記：記憶條目；付出後內文變成被整齊剪掉的空白，只留下殘留的一句
- 暫停選單、設定選單（難度、語言、主音量／音樂／音效／語音、字幕、畫質三級、全螢幕、垂直同步、減少鏡頭晃動）、HUD（目前目標、存檔提示、目標指引：指向下一個目標的小菱形＋距離，可在設定關掉）
- 對話系統：逐字浮現、選項、按住跳過；付出記憶後，相關的對話選項會消失
- 按鍵重新綁定（鍵鼠＋手把、衝突自動交換），提示依目前裝置顯示 [F] 或手把按鈕圖示
- 過場與可互動演出：黑邊、字幕、按住跳過；敲鐘九下（每下一個輸入）、北街陷落
- 戰鬥：鐘錘命中、打擊停頓、鏡頭震動、練習木樁；看穿（已證實／未證實）與弱點方向判定；鎖定目標（被擋解除、左右換目標）、戰鬥鏡頭；灰巡者（前兆、爪擊、失衡跪地）；倒下後從檢查點重來；戰鬥 HUD（生命、體力、指令冷卻）
- 送葬者戰（兩階段）：橫掃／下砸／衝撞 → 第二階段攻略失準（連續下砸、抓取＋掙扎），轉追傷者車隊；鐵架拋擲時重現南街石拱擋下（鐵架真的飛出去、撞在石縫透著冷光的石拱上碎掉），或由席菈提前燒劍在車隊前把它斬成兩截；車隊通過路口即結束，送葬者跪下、向前倒地
- 重現：提示寫明效果與代價、按住預覽、重現時畫面去飽和、九聲心跳、化灰；付出的記憶讓之後的對話選項消失。玩家看到的用詞都是白話（[對照表](docs/design/06-terminology.md)）
- 同伴席菈：跟隨、自主斬擊、三個指令（時機窗依難度、冷卻、拒絕附理由——例如在傷者旁不肯閃開、頭上回話）、倒下 8 秒內可拉起
- 難度三級（故事／標準／困難，即時套用）；程序生成音效（鐘聲、打擊、爪擊、斬擊、閃避）
- 效能 overlay（F3）與 benchmark：`YumingCity.exe ++ --benchmark`，結果寫到 `%APPDATA%\YumingCity\benchmark\`
